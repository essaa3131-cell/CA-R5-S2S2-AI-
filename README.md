## Getting Started

### Prerequisites
- Python 3.x installed on your machine

### Clone the Repository
```bash
git clone https://github.com/essaa3131-cell/CA-R5-S2S2-AI-.git
cd CA-R5-S2S2-AI-
```

### Run the Scripts
```bash
cd python-for-ml
python hello.py
python data_types.py
```

| File | Description |
